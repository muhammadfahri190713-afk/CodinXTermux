# Contoh

| File | Salin ke | Fungsi |
|---|---|---|
| `AGENTS.md` | root proyek | instruksi proyek untuk agent |
| `hooks.json` | `~/.codinx/hooks.json` | hooks Pre/PostToolUse, UserPromptSubmit |
| `mcp.json` | `~/.codinx/mcp.json` | daftar server MCP |
| `mcp-echo-server.py` | `/opt/codinx/examples/` | server MCP contoh (echo, add) |
| `skills/hello-skill/` | `~/.codinx/skills/` | skill contoh |
| `agents/reviewer-strict.md` | `~/.codinx/agents/` | sub-agent contoh |
| `commands/standup.md` | `~/.codinx/commands/` | perintah custom contoh |
| `project-config.json` | `<proyek>/.codinx/config.json` | override konfigurasi per proyek (hanya kunci aman) |
