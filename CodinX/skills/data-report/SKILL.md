# Laporan data
1. Inspeksi: kolom, tipe, jumlah baris, nilai kosong (`python3` via bash).
2. Hitung statistik inti (min/maks/rata-rata/top-N) dan tampilkan dengan tool `table`.
3. Tulis 3-5 temuan utama dalam bullet; sebut angka pastinya.
4. Simpan hasil ke file bila diminta (`table` save_as, atau `write` untuk .md).
