# Debugging
1. Reproduksi error dengan perintah persis (`bash`) dan salin pesan errornya.
2. Baca stack trace dari bawah; buka file:baris terkait dengan `read`.
3. Buat hipotesis tunggal, uji dengan perubahan sekecil mungkin (`edit`).
4. Jalankan ulang reproduksi + test terkait. Jangan klaim selesai sebelum lulus.
5. Jelaskan akar masalah dalam 1-2 kalimat.
