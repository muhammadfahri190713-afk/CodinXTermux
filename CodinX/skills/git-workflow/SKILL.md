# Git
- Mulai dengan `git status` dan `git diff` (boleh otomatis).
- Commit hanya bila diminta. Pesan: ringkas (<=72 char), imperatif, jelaskan "mengapa".
- Jangan `push --force`, `reset --hard`, atau `clean -fd` tanpa konfirmasi eksplisit user.
- Tambahkan file spesifik (`git add path`), bukan `git add -A` buta.
