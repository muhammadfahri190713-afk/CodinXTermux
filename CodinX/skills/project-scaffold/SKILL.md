# Scaffold
1. Tanyakan hanya jika stack benar-benar ambigu; jika tidak, pilih default sederhana.
2. Struktur minimal: README.md, .gitignore, entry point, satu test, skrip run/build.
3. Node: `package.json` dengan scripts start/test. Python: `pyproject.toml` atau `requirements.txt` + `main.py`.
4. Jalankan sekali untuk memverifikasi, lalu tampilkan pohon folder hasilnya.
