# AGENTS.md (contoh)
Panduan untuk agent coding di proyek ini. Letakkan di root repo; CodinX membacanya otomatis.

## Perintah
- Install: `npm ci` · Test: `npm test` · Lint: `npm run lint` · Jalankan: `npm run dev` (port 3000)

## Konvensi
- TypeScript strict; komponen fungsi; nama file kebab-case.
- Jangan commit `.env`; gunakan `.env.example`.
- Setiap perubahan perilaku wajib disertai test.
